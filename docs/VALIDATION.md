# 本轮改版与验收

## 目标与方案

解决不知道点击顺序、功能入口过多、流程可能互相冲突的问题。基于现有源码继续开发，保持 Python / PySide6 / faster-whisper / CTranslate2 / FFmpeg 路线，无新运行时依赖，无在线 API 费用。

默认工作流：选择视频 → 选择目标语言 → 一键识别并翻译 → 校对 → 明确选择导出。

## 修改范围

- `src/simplecaption/window.py`：自动阶段衔接、忙碌入口锁定、字幕校对与自动备份、语言切换、停止后续步骤、手动导出。
- `src/simplecaption/guided_ui.py`：简化界面、原视频预览、字幕定位、默认折叠高级选项。
- `src/simplecaption/export_worker.py`：默认只烧录译文，不自动打马赛克；临时文件成功后替换目标，失败时保留已有成品。
- `src/simplecaption/ui_check.py`、`src/localvideoai/app.py`：实际 Qt 与发布包界面检查入口。
- `packaging/localvideoai.spec`：纳入新模块，使用 PyInstaller 对实际 Qt 模块的钩子，不再 collect_all 全套 PySide6 模块。
- `tests/test_guided_workflow.py`：新流程、互斥、异常、导出与文件保护回归。
- `tests/test_simplecaption.py`：更新明确变更的入口文案与默认行为预期。
- `.gitignore`、`.github/workflows/tests.yml`、`scripts/audit_repository.py`、README 与 GitHub 准备说明：源码发布准备。
- `启动视频翻译.cmd`：单一新版启动入口。

这是从原目录迁移到独立源码目录的首次提交，因此 Git 初始提交会包含原有底层模块。原目录源码及用户复制的 `LocalVideoAI/` 程序没有改写。

## 行为与兼容性

- 主按钮自动衔接识别与翻译，翻译后停止供人工校对，不自动改画面。
- 默认不启用马赛克；可在高级选项中显式开启，并确认其固定区域遮挡风险。
- 处理时禁止换文件、改参数、编辑字幕、重复启动和切换高级工作站。
- 高级工作站打开时隐藏简易窗口，关闭后返回，防止两个可操作界面并行启动任务。
- 支持修改原文和译文，原文变更使该句旧译文失效，缺译文时阻止正式导出。
- 原文与译文备份放到视频旁独立时间戳目录，切换目标语言前备份旧译文。
- 无 API、数据库结构或项目文件格式变更；没有改变模型与识别推理参数。

- 36 项相关回归测试通过：`test_simplecaption.py`、`test_guided_workflow.py`、`test_cuda_language_route.py`、`test_subtitles_phase4.py`。
- 自动串联仅在识别线程完成后进入翻译；失败和空结果不进入下一步。
- 停止后续步骤、忙碌时禁止换文件和打开高级工作站、完整模式返回已测试。
- 人工修改落到 SRT、目标语言切换备份、漏译阻止导出已测试。
- 实际 FFmpeg 字幕视频导出与解码通过；原视频 SHA256 保持一致，失败导出保留原目标文件。
- Windows 实际 Qt 界面检查通过，中文显示正常；offscreen 截图中文字有方框，采用 Windows 原生截图复核。
- 使用约 4 秒的真实音频测试夹具，实际 UI 线程串联识别和翻译，返回校对状态，得到 1 句非空译文，没有自动导出视频。
- PyInstaller 构建成功；发布版 EXE `--guided-ui-check` 退出码 0，成功生成截图。
- Python 编译检查通过；源码上传候选大小、排除路径与疑似密钥启发式检查通过。

## 验证中发现并修正的问题

- 迁移初期未带生成的字幕和媒体夹具，旧测试因此失败；补齐本地夹具后通过，夹具不上传仓库。
- 清理界面导入时遗漏 QLabel，界面测试失败；补回导入并重跑通过。
- 首次真实音频测试因沙箱不能写默认 AppData 而失败；改用项目内隔离测试目录重跑通过。发布程序启用便携数据目录。
- 旧打包配置无差别收集 Qt 模块，带入大量未使用模块；调整后构建成功。

## 未验证与限制

- 没有对长电影、全语种、不同显卡与其他 Windows 机器做完整端到端验收。
- 高级工作站的 OCR、批量、实时预览、说话人和修复没有全量重验，不能声称所有旧功能冲突已消除。
- 原视频预览不显示最终烧录字幕效果；成片需要导出后查看。
- 马赛克仍为固定区域，NVENC 不可用时该路径可能失败；默认普通导出使用 CPU H.264。
- 「停止」在阶段边界生效，不能瞬间中止一次模型调用；视频导出需要等待结束。
- 翻译质量没有模型升级；一条音频通过不能证明长片翻译质量与速度。
- 未运行独立 Lint 或性能基准，不作性能提升承诺；GitHub Actions 尚待远程实际运行。
- 仓库启发式扫描不等于完整安全审计；正式分发需复核第三方运行库、模型与 FFmpeg 的许可。
